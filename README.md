# Summary.
A voice-controlled thermostat regulation system built with an STM32 microcontroller featuring real-time PID control, wireless connectivity, and e-paper display. The system uses a BME280 sensor for environmental monitoring (temperature, humidity, and pressure), ESP32 for WiFi and Google Home integration via Sinric Pro, and PWM-controlled fan for proportional cooling. The thermostat is designed with solenoid valve capability to control pneumatic airflow for HVAC systems, providing for efficient temperature regulation, and retrofitting older buildings with modern smart temperature device control.

Technologies used: Arduino, STM32 (IDE/MX), C/C++
